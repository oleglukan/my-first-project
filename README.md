# Навчальний проєкт

## 1. Опис проєкту
Практичний проєкт, створений у межах виконання лабораторних робіт з IT-напрямку. Проєкт призначений для засвоєння базових навичок роботи з веб-технологіями та системою контролю версій Git.

## 2. Використані технології
- HTML5 / CSS3
- JavaScript (ES6+)
- Git / GitHub

## 3. Основний функціонал
- Базова структура сторінки та стилізація елементів.
- Інтерактивні сценарії на боці клієнта.
- Збереження та відображення даних.

## 4. Інструкція із запуску та встановлення
1. Клонувати репозиторій: `git clone https://github.com/oleglukan/my-first-project.git`
2. Перейти у директорію проєкту: `cd my-first-project`
3. Відкрити файл `index.html` у будь-якому браузері.
